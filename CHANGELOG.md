# Changelog

All notable changes to this project are documented in this file. This project
follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.1.0 - 2026-07-23

### Added

- Typed clients for eGov AI, eGovChain, eGov Compass, eGov Face Liveness,
  eGovPay, eGov SSO, eMessage, eReport, and eVerify.
- ESM and CommonJS builds with TypeScript declarations and service subpath
  exports.
- Holocron documentation, package validation, tests, and release automation.
