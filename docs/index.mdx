# Typed access to Philippine eGov APIs

**egov.js** is a dependency-free JavaScript and TypeScript SDK for nine eGov
partner services. It standardizes authentication, request construction, error
handling, and public types without hiding the underlying API contracts.

<Warning>
  Most configured endpoints are **hackathon or staging services**. Confirm the correct production
  host and access agreement with each service owner before serving real users.
</Warning>

## Start with one service

**Subpath imports** keep each integration explicit and tree-shakeable. Choose a
service, create a client, and pass its base URL separately from credentials.

## Runtime model

**Modern web standards** power the SDK: Fetch, `Headers`, `URL`, `FormData`,
`Blob`, and Web Crypto. Node.js 22.18 or newer is the supported server runtime.

<Aside>
  <Info>
    Credential-bearing clients belong on the **server**, even when the runtime APIs also exist in a
    browser.
  </Info>
</Aside>

**No automatic retries** are performed. Payment, messaging, complaint, and
biometric operations can have side effects, so retry policy belongs to the
application that understands idempotency.
