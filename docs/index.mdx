# Generated access to Philippine eGov APIs

**egov.js** publishes an OpenAPI 3.1 contract and a TypeScript SDK generated
from it with Hey API. The root package exports a Fetch client, tagged static
service classes, and all request and response types.

<Info>
  **egov.js is an unofficial, community-maintained SDK.** It is not affiliated with, endorsed by, or
  supported by the Department of Information and Communications Technology (DICT), eGov PH, or any
  Philippine government agency. Credentials and quotas are issued by eGov at
  [platforms.e.gov.ph](https://platforms.e.gov.ph).
</Info>

<Warning>
  Provider endpoints are **staging or hackathon services** unless confirmed otherwise. Keep
  credentials and citizen data on trusted server infrastructure.
</Warning>

## Runtime model

The generated SDK uses Fetch, `Headers`, `URL`, `FormData`, and `Blob`. Node.js
22.18 or newer is the supported server runtime. The package bundles its client
and has no runtime dependencies.

The SDK does not retry automatically. Payment, messaging, complaint, blockchain,
and biometric operations can have external side effects, so retry policy belongs
to the application.
