# Import package exports

## Root SDK

The root entry exports `createClient`, tagged static classes for every service,
and all generated request and response types.

```ts
import { createClient, egovAi } from "egov.js";
import type { EgovAiPromptRequest } from "egov.js";
```

The package ships matching ESM, CommonJS, and TypeScript declaration outputs.

```js
const { createClient } = require("egov.js");
```

Service and `/types` subpaths from the handwritten SDK are no longer exported.

## OpenAPI document

Import the canonical OpenAPI 3.1 JSON document directly:

```ts
import openapi from "egov.js/openapi.json" with { type: "json" };

console.log(Object.keys(openapi.paths));
```

CommonJS consumers can require it:

```js
const openapi = require("egov.js/openapi.json");
```

External generators can resolve the installed file:

```ts
import { fileURLToPath } from "node:url";

const openapiPath = fileURLToPath(import.meta.resolve("egov.js/openapi.json"));
```

The public export boundary is intentionally small: `egov.js`,
`egov.js/openapi.json`, and `egov.js/package.json`.
