# Use Face Liveness

**Face Liveness** creates hosted biometric verification sessions and returns the result associated with each session token.

<Aside>
  <Warning>
    Biometric images and results are **sensitive personal data**. Keep API keys and verification
    data on trusted server infrastructure.
  </Warning>
</Aside>

## Connect

Configure the documented **hackathon host** and integration API key:

```ts
import { createClient } from "egov.js";

const faceLivenessClient = createClient({
  baseUrl: "https://hackathon-face-liveness-api.e.gov.ph",
  headers: { "x-api-key": process.env.EGOVLIVENESS_API_KEY! },
});
```

## Methods

The **API Reference tab** documents the complete session request, hosted verification URL, path parameter, and result schema.

### `faceLiveness.createSession`

**`POST /v1/liveness/session`** creates a biometric verification session and returns its session token and hosted verification URL.

```ts
import { faceLiveness } from "egov.js";

const session = await faceLiveness.createSession({
  client: faceLivenessClient,
  body: {
    action: "redirect",
    callback_url: "https://example.gov.ph/identity/liveness-complete",
  },
  throwOnError: true,
});
```

### `faceLiveness.getVerificationResult`

**`GET /v1/liveness/result/{sessionToken}`** returns the biometric result associated with an existing session token.

```ts
import { faceLiveness } from "egov.js";

const result = await faceLiveness.getVerificationResult({
  client: faceLivenessClient,
  path: { sessionToken: session.token },
  throwOnError: true,
});
```
