# Use eGovChain

**eGovChain** exposes an EVM-compatible JSON-RPC endpoint for blockchain reads, contract calls, event logs, and raw transaction submission.

<Aside>
  <Warning>
    The documented **hackathon network** is not a production chain. Raw transaction submission can
    still create permanent network state.
  </Warning>
</Aside>

## Authentication

The gateway token is part of the request path. Read it from `EGOVCHAIN_TOKEN` and pass it through the generated `path` options; do not put it in headers or logs.

## Initialize the client

Create a **dedicated client** for the configured eGovChain gateway:

```ts
import { createClient } from "egov.js";

const client = createClient({
  baseUrl: process.env.EGOVCHAIN_BASE_URL!,
});
```

## Methods

The example below uses this **eGovChain client**. See [the quickstart](../getting-started/quickstart.mdx) for the general client pattern.

The **API Reference tab** documents the generic JSON-RPC envelope, success and error responses, and a catalog of supported RPC variants.

### `egovChain.jsonRpc`

**`POST /{token}`** sends a JSON-RPC method, optional parameters, and request identifier to the eGovChain endpoint.

```ts
import { egovChain } from "egov.js";

const blockNumber = await egovChain.jsonRpc({
  client,
  path: { token: process.env.EGOVCHAIN_TOKEN! },
  body: {
    id: 1,
    jsonrpc: "2.0",
    method: "eth_blockNumber",
    params: [],
  },
  throwOnError: true,
});
```

The operation's **`x-egov-rpc-catalog` extension** lists 70 supported variants for chain metadata, blocks, transactions, receipts, calls, logs, filters, tracing, and raw transaction submission.
