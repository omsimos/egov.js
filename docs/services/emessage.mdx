# Use eMessage

**eMessage** sends authenticated SMS notifications to a mobile number through the Philippine eGov messaging service.

<Aside>
  <Warning>
    Sending an SMS creates an **external side effect** and may expose citizen contact data. Keep the
    provider token in server-side code.
  </Warning>
</Aside>

## Connect

Configure the documented **provider host** and eMessage token:

```ts
import { createClient } from "egov.js";

const eMessageClient = createClient({
  baseUrl: "https://ws-message.e.gov.ph",
  headers: { "X-EMESSAGE-Auth": process.env.EMESSAGE_ACCESS_TOKEN! },
});
```

## Delivery policy

Apply **retry and duplicate-suppression policy** in the application because the generated client does not retry automatically.

## Methods

The **API Reference tab** documents the complete message body, authentication header, validation errors, and success response.

### `eMessage.sendSms`

**`POST /messaging/v1/sms/push`** sends an SMS message to the supplied mobile number using the configured eMessage token.

```ts
import { eMessage } from "egov.js";

const message = await eMessage.sendSms({
  client: eMessageClient,
  body: {
    message: "Your application is ready for review.",
    number: "+639171234567",
  },
  throwOnError: true,
});
```
