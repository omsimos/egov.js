# Build citizen transactions

## eMessage

**eMessage currently supports SMS push** through the SDK. Recipient numbers use
E.164 format.

```ts
import { eMessageApi } from "@omsimos/egov/eMessage";

const messaging = eMessageApi.fromEnv({
  baseUrl: "https://ws-message.e.gov.ph",
});

await messaging.sendSms({
  message: "Your request has been received.",
  number: "+639171234567",
});
```

## eReport

**eReport supports an OTP-gated complaint workflow** plus report categories and
region-to-barangay location datasets.

```ts
import { eReportApi } from "@omsimos/egov/eReport";

const reports = eReportApi.fromEnv({
  baseUrl: "https://stg-ereport-ws.oueg.info",
});

const token = await reports.generateToken();
const types = await reports.listReportTypes(token.access_token);
```

## eGovPay

**eGovPay signs payment requests** with HMAC-SHA256 and supports transaction
creation, lookup, and voiding.

```ts
import { eGovPayApi } from "@omsimos/egov/eGovPay";

const payments = eGovPayApi.fromEnv({
  baseUrl: "https://egovpay-pgi-ws-dev.oueg.info",
});

const transaction = await payments.getTransaction(transactionUuid);
```

<Warning>
  These methods can **send messages or change external records**. Add business confirmation, audit
  logging, and provider-supported idempotency before retrying any write.
</Warning>
