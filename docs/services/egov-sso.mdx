# Use eGov SSO

**eGov SSO** exchanges partner credentials and a citizen authorization code for an access token, then returns the authenticated citizen profile.

<Aside>
  <Warning>
    SSO responses contain **personally identifiable information**. Keep partner secrets, tokens, and
    citizen profiles on trusted server infrastructure.
  </Warning>
</Aside>

## Connect

Create a dedicated **provider client** for the documented hackathon host:

```ts
import { createClient } from "egov.js";

const egovSsoClient = createClient({
  baseUrl: "https://hackathon-sso.e.gov.ph",
});
```

## Authentication flow

Call **`egovSso.generateAccessToken`** with the partner code, partner secret, and exchange code. Pass the returned bearer token to `egovSso.authenticate` through `auth`.

## Methods

The **API Reference tab** documents token-exchange errors, bearer authentication, request fields, and the citizen profile schema.

### `egovSso.generateAccessToken`

**`POST /api/token`** exchanges the partner code, partner secret, and citizen authorization code for an access token.

```ts
import { egovSso } from "egov.js";

const token = await egovSso.generateAccessToken({
  client: egovSsoClient,
  body: {
    exchange_code: authorizationCode,
    partner_code: process.env.EGOVSSO_PARTNER_CODE!,
    partner_secret: process.env.EGOVSSO_PARTNER_SECRET!,
    scope: "SSO_AUTHENTICATION",
  },
  throwOnError: true,
});
```

### `egovSso.authenticate`

**`POST /api/partner/sso_authentication`** uses the bearer token to return the authenticated citizen profile.

```ts
import { egovSso } from "egov.js";

const citizen = await egovSso.authenticate({
  client: egovSsoClient,
  auth: token.access_token,
  throwOnError: true,
});
```
