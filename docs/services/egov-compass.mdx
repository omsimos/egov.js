# Use Compass

**Compass** provides structured access to Philippine budget execution, allocation, release, and Local Government Support Fund records.

<Aside>
  <Note>
    Compass operations are **read-only queries**, but access still requires the API key issued to
    your integration.
  </Note>
</Aside>

## Connect

Configure the documented **provider host** and `x-api-key` header once:

```ts
import { createClient } from "egov.js";

const compassClient = createClient({
  baseUrl: "https://dbm-ws.oueg.info",
  headers: { "x-api-key": process.env.EGOVCOMPASS_API_KEY! },
});
```

## Query model

Pass request filters under the operation's **`query` object**. Required year, period, scope, and program fields vary by dataset.

## Methods

The **API Reference tab** remains the source of truth for complete query parameters, response schemas, and cURL examples.

### `compass.getSaaodbRecords`

**`GET /api/v1/records/saaodb`** returns paginated SAAODB budget-execution records filtered by year, period, scope, entity, or expense class.

```ts
import { compass } from "egov.js";

const saaodb = await compass.getSaaodbRecords({
  client: compassClient,
  query: {
    period: "FY",
    reportYear: 2026,
    page: 1,
    limit: 25,
  },
  throwOnError: true,
});
```

### `compass.getSaaodbDashboard`

**`GET /api/v1/records/saaodb/dashboard`** returns aggregated SAAODB figures for the requested report year and sheet scope.

```ts
import { compass } from "egov.js";

const saaodbDashboard = await compass.getSaaodbDashboard({
  client: compassClient,
  query: {
    reportYear: 2026,
    sheetScope: "summary",
  },
  throwOnError: true,
});
```

### `compass.getSaaodbEntities`

**`GET /api/v1/records/saaodb/entities`** returns department, agency, and fund-source relationships for navigating SAAODB data.

```ts
import { compass } from "egov.js";

const entities = await compass.getSaaodbEntities({
  client: compassClient,
  query: {
    reportYear: 2026,
    sheetScope: "agency",
  },
  throwOnError: true,
});
```

### `compass.getNcaRecords`

**`GET /api/v1/records/nca`** returns paginated Notice of Cash Allocation records for a budget year and optional organization filters.

```ts
import { compass } from "egov.js";

const nca = await compass.getNcaRecords({
  client: compassClient,
  query: {
    budgetYear: 2026,
    page: 1,
    limit: 25,
  },
  throwOnError: true,
});
```

### `compass.getSaroRecords`

**`GET /api/v1/records/saro`** returns paginated Special Allotment Release Order records with optional release and agency filters.

```ts
import { compass } from "egov.js";

const saro = await compass.getSaroRecords({
  client: compassClient,
  query: { page: 1, limit: 25 },
  throwOnError: true,
});
```

### `compass.getLgsfRecords`

**`GET /api/v1/records/lgsf`** returns paginated Local Government Support Fund records with optional program and location filters.

```ts
import { compass } from "egov.js";

const lgsf = await compass.getLgsfRecords({
  client: compassClient,
  query: {
    fiscalYear: 2026,
    programCode: "FALGU",
    page: 1,
    limit: 25,
  },
  throwOnError: true,
});
```

### `compass.getLgsfDashboard`

**`GET /api/v1/records/lgsf/dashboard`** returns LGSF KPIs, trends, and projects for the requested program and optional location filters.

```ts
import { compass } from "egov.js";

const lgsfDashboard = await compass.getLgsfDashboard({
  client: compassClient,
  query: {
    programCode: "FALGU",
    reportYear: 2026,
  },
  throwOnError: true,
});
```
