# eGov Compass API reference

The eGov Compass client reads SAAODB, SARO, NCA, and LGSF budget data. All seven
client methods are read-only HTTP `GET` operations.

<Note>
  Only [`getSaaodbRecords`](#getsaaodbrecords) requires a `period`. `getSaaodbDashboard` and
  `getSaaodbEntities` do not accept a `period` field.
</Note>

**Factories**

| Factory                      | Returns         | Credential source        |
| ---------------------------- | --------------- | ------------------------ |
| `eGovCompassApi.create`      | `CompassClient` | Explicit `apiKey` option |
| `createCompassClient`        | `CompassClient` | Explicit `apiKey` option |
| `eGovCompassApi.fromEnv`     | `CompassClient` | `EGOVCOMPASS_API_KEY`    |
| `createCompassClientFromEnv` | `CompassClient` | `EGOVCOMPASS_API_KEY`    |

**Catalog exports**

| Runtime export           | Description                                                         |
| ------------------------ | ------------------------------------------------------------------- |
| `eGovCompassApi`         | Shallow-frozen facade containing `create`, `fromEnv`, and `catalog` |
| `eGovCompassApi.catalog` | The same object as `compassCatalog`                                 |
| `compassCatalog`         | Machine-readable metadata for the seven Compass endpoints           |
| `COMPASS_SOURCE_URL`     | eGov API catalog source URL                                         |

**Methods**

The methods below are in `CompassClient` source order.

| Method                                    | Purpose                                           |
| ----------------------------------------- | ------------------------------------------------- |
| [getLgsfDashboard](#getlgsfdashboard)     | Return LGSF KPIs, projects, and trend records     |
| [getLgsfRecords](#getlgsfrecords)         | Return paginated LGSF records                     |
| [getNcaRecords](#getncarecords)           | Return paginated Notices of Cash Allocation       |
| [getSaaodbDashboard](#getsaaodbdashboard) | Return aggregate SAAODB budget-execution figures  |
| [getSaaodbEntities](#getsaaodbentities)   | Return SAAODB entity hierarchy data               |
| [getSaaodbRecords](#getsaaodbrecords)     | Return paginated SAAODB budget-execution records  |
| [getSaroRecords](#getsarorecords)         | Return paginated Special Allotment Release Orders |

below. It does not re-export the Compass interfaces and type aliases.

**`eGovCompassApi`**

`eGovCompassApi` is a shallow-frozen runtime facade. Its properties refer to
the same direct exports documented on this page.

```ts
const eGovCompassApi = Object.freeze({
  catalog: compassCatalog,
  create: createCompassClient,
  fromEnv: createCompassClientFromEnv,
});
```

Freezing the facade prevents replacing its three properties. It does not add
validation to factory options, requests, responses, or the separate
`compassCatalog` object.

**`createCompassClient`**

**Signature**

```ts
function createCompassClient(options: CompassClientOptions): CompassClient;
```

`eGovCompassApi.create` is the same function.

**Parameters**

| Option    | Type          | Required | Behavior                                                                                                                             |
| --------- | ------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `apiKey`  | `string`      | Yes      | Sent as `X-API-Key` on every client request. The factory does not explicitly trim or validate it before passing it to `Headers.set`. |
| `baseUrl` | `string`      | Yes      | Base URL against which each endpoint path is resolved. There is no SDK default and it is not read from an environment variable.      |
| `fetch`   | `EgovFetch`   | No       | Custom Fetch-compatible implementation. Defaults to `globalThis.fetch`.                                                              |
| `headers` | `HeadersInit` | No       | Headers applied to every request before per-call headers and Compass authentication are applied.                                     |

`EgovFetch` has this signature:

```ts
type EgovFetch = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>;
```

**Returns**

A `CompassClient` with the seven methods in the Methods table. The
factory creates the transport synchronously and does not make a network request.

**Behavior and errors**

The factory supplies no API host, credential, timeout, retry, query, or
pagination defaults. It performs no Compass-specific runtime validation. Header
construction can surface native `Headers` errors; request-time URL and Fetch
errors follow the shared error behavior.

```ts
import { eGovCompassApi } from "egov.js/eGovCompass";

const compass = eGovCompassApi.create({
  apiKey: await secrets.get("EGOVCOMPASS_API_KEY"),
  baseUrl: "https://dbm-ws.oueg.info",
});
```

**`createCompassClientFromEnv`**

**Signature**

```ts
function createCompassClientFromEnv(options: CompassEnvironmentClientOptions): CompassClient;
```

`eGovCompassApi.fromEnv` is the same function.

**Parameters**

| Option    | Type              | Required | Behavior                                                                                                           |
| --------- | ----------------- | -------- | ------------------------------------------------------------------------------------------------------------------ |
| `baseUrl` | `string`          | Yes      | Explicit service base URL. No base URL environment variable is read.                                               |
| `env`     | `EgovEnvironment` | No       | Complete environment object to use instead of runtime globals. Only `EGOVCOMPASS_API_KEY` is read by this factory. |
| `fetch`   | `EgovFetch`       | No       | Custom Fetch-compatible implementation. Defaults to `globalThis.fetch`.                                            |
| `headers` | `HeadersInit`     | No       | Headers applied to every request before per-call headers and Compass authentication.                               |

The environment option has this shared core shape:

```ts
type EgovEnvironment = Readonly<
  Partial<Record<EgovEnvironmentName, string>> & Record<string, string | undefined>
>;
```

It is structurally a readonly, string-keyed environment object. The known eGov
environment names are optional; Compass reads only `EGOVCOMPASS_API_KEY`.

Environment object selection occurs in this exact order:

1. `options.env`, when provided
2. `globalThis.Bun?.env`
3. `globalThis.process?.env`
4. An empty object

The first available object is selected as a whole. The factory does not search
later objects for a missing key: `options.env` prevents fallback to Bun or Node,
and an available `Bun.env` prevents fallback to `process.env`. The selected
`EGOVCOMPASS_API_KEY` value is trimmed. A missing, empty, or whitespace-only
value throws a plain `Error` with this exact message:

```text
Missing required eGov environment variable: EGOVCOMPASS_API_KEY
```

**Returns**

A `CompassClient` configured with the resolved API key and the explicit
transport options.

**Behavior and errors**

Environment lookup and the missing-key error happen synchronously. No request
is sent by the factory. After the key is resolved, request behavior and failures
are the same as for `createCompassClient`.

```ts
import { eGovCompassApi } from "egov.js/eGovCompass";

const compass = eGovCompassApi.fromEnv({
  baseUrl: "https://dbm-ws.oueg.info",
});
```

**`compassCatalog`**

`compassCatalog` is runtime metadata, and `eGovCompassApi.catalog` refers to the
same object.

| Field       | Value                                                                          |
| ----------- | ------------------------------------------------------------------------------ |
| `id`        | `"compass"`                                                                    |
| `name`      | `"Compass"`                                                                    |

| Catalog ID                         | Name                             | Wire route                             | Catalog response description |
| ---------------------------------- | -------------------------------- | -------------------------------------- | ---------------------------- |
| `get-saaodb-records`               | Get SAAODB Records               | `GET /api/v1/records/saaodb`           | SAAODB records returned.     |
| `get-saaodb-dashboard-summary`     | Get SAAODB Dashboard Summary     | `GET /api/v1/records/saaodb/dashboard` | SAAODB dashboard returned.   |
| `get-saaodb-hierarchical-entities` | Get SAAODB Hierarchical Entities | `GET /api/v1/records/saaodb/entities`  | Entity hierarchy returned.   |
| `get-nca-records`                  | Get NCA Records                  | `GET /api/v1/records/nca`              | NCA records returned.        |
| `get-saro-records`                 | Get SARO Records                 | `GET /api/v1/records/saro`             | SARO records returned.       |
| `get-lgsf-records`                 | Get LGSF Records                 | `GET /api/v1/records/lgsf`             | LGSF records returned.       |
| `get-lgsf-dashboard-summary`       | Get LGSF Dashboard Summary       | `GET /api/v1/records/lgsf/dashboard`   | LGSF dashboard returned.     |

The catalog describes discovery metadata. The TypeScript query and response
contracts in `egov.js/eGovCompass/types` are the client method contracts.

**Shared request behavior**

All Compass methods use the same transport behavior:

- Each call sends one read-only `GET` request with no request body. The SDK does
  not retry automatically.
- The endpoint path is resolved against the configured `baseUrl`. A missing
  trailing slash is normalized before the path is resolved.
- Query values are serialized with `String(value)`. `undefined` values are
  omitted. The core transport also omits `null`, although public Compass query
  types do not accept `null`.
- Factory-level headers are applied first, then per-call headers. The configured
  API key is set last as `X-API-Key`, so neither header set can replace it.
- `Accept: application/json` is added only when the merged headers do not
  already contain an `Accept` header.
- The SDK supplies no service query or pagination defaults. Type requirements,
  integer annotations, and string unions are compile-time contracts only; the
  SDK does not validate query values at runtime.
- Successful response bodies are parsed as JSON only for `application/json` or
  a media type ending in `+json`. Other bodies, including malformed declared
  JSON, are returned as text. Empty bodies and status `204` or `205` produce
  `undefined` at runtime.
- Parsed successful bodies are cast to the documented TypeScript return type.
  The SDK does not validate response fields, nesting, unions, or open record
  contents at runtime.

Bypassing TypeScript and omitting an individual required query field generally
causes that field to be omitted from the URL. Omitting a required query object
can instead cause a native property-access `TypeError` before Fetch is called.

**Shared pagination**

The record-list queries extend this shared query type:

```ts
interface CompassPaginationQuery {
  limit?: number;
  page?: number;
}
```

Both fields are optional. The SDK does not assign a default, enforce an integer
or range, or interpret the values. When provided, each is serialized as a query
string value and sent to the provider.

`getLgsfRecords`, `getNcaRecords`, `getSaaodbRecords`, and `getSaroRecords`
return this shared envelope:

```ts
interface CompassPaginatedResponse<T> {
  items: T[];
  limit: number;
  page: number;
  total: number;
}
```

All four response fields are required by the TypeScript contract. The LGSF
dashboard accepts the shared `limit` and `page` query fields but uses its own
`projects` response shape with `pageSize` rather than `limit`.

**Shared call options**

Every method accepts the same optional final argument. Import its type from
`egov.js/core`.

```ts
interface EgovCallOptions {
  headers?: HeadersInit;
  signal?: AbortSignal;
}
```

| Field     | Behavior                                                                                                                                                        |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `headers` | Adds or replaces headers for this call after factory-level headers. `X-API-Key` is subsequently set to the configured credential and cannot be overridden here. |
| `signal`  | Passed directly to Fetch as `RequestInit.signal`. The SDK does not create a timeout signal.                                                                     |

For a method whose `query` argument is optional, pass `undefined` in the first
position when supplying call options without filters:

```ts
await compass.getSaroRecords(undefined, {
  signal: AbortSignal.timeout(10_000),
});
```

**Shared errors**

A non-successful HTTP response throws `EgovApiError` from `egov.js/core` after
the response body is parsed according to the shared response
behavior.

| Property     | Type      | Value                                                                          |
| ------------ | --------- | ------------------------------------------------------------------------------ |
| `name`       | `string`  | `"EgovApiError"`                                                               |
| `message`    | `string`  | `"GET <url> failed with <status> <statusText>"`, with outer whitespace trimmed |
| `body`       | `unknown` | Parsed JSON, text, or `undefined` response body                                |
| `headers`    | `Headers` | Response headers                                                               |
| `method`     | `string`  | `"GET"` for every Compass method                                               |
| `status`     | `number`  | HTTP status code                                                               |
| `statusText` | `string`  | HTTP status text                                                               |
| `url`        | `string`  | Fully resolved request URL, including serialized query fields                  |

Fetch rejections, abort errors, URL construction errors, and other native
runtime errors propagate unchanged; the SDK does not wrap them in
`EgovApiError`.

does not default `reportYear`, pagination, or filters and does not validate the
query or response at runtime. See shared request behavior
and shared errors.
