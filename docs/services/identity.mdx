# Verify citizens

## eGov SSO

**SSO exchanges a one-time code** for an access token, then retrieves a citizen
profile from the partner authentication endpoint.

```ts
import { eGovSsoApi } from "egov.js/eGovSso";

const sso = eGovSsoApi.fromEnv({
  baseUrl: "https://hackathon-sso.e.gov.ph",
});

const token = await sso.generateAccessToken({
  exchangeCode,
  scope: "SSO_AUTHENTICATION",
});
const citizen = await sso.authenticate(token.access_token);
```

## eVerify

**eVerify authenticates server credentials** before personal-information or QR
verification. The environment client also exposes the configured public key.

```ts
import { eVerifyApi } from "egov.js/eVerify";

const verify = eVerifyApi.fromEnv({
  baseUrl: "https://hackathon-everify-api.e.gov.ph",
});

const token = await verify.authenticate();
```

## Face Liveness

**Face Liveness creates a hosted verification session** and returns a result for
the resulting session token.

```ts
import { eGovFaceLivenessApi } from "egov.js/eGovFaceLiveness";

const liveness = eGovFaceLivenessApi.fromEnv({
  baseUrl: "https://hackathon-face-liveness-api.e.gov.ph",
});

const session = await liveness.createSession({
  action: "redirect",
  callbackUrl: "https://example.gov.ph/verify/complete",
});
```

<Warning>
  Citizen profiles and biometric results are **highly sensitive personal data**. Minimize
  collection, encrypt storage, redact logs, and follow the applicable data-sharing agreement and
  Philippine privacy requirements.
</Warning>
