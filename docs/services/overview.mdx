# Choose an eGov service

**Nine service clients** share one transport and error model while preserving
each provider's authentication and response types.

| Service       | Capability                                              | Environment credentials                                        | Side effects                    |
| ------------- | ------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------- |
| eGov AI       | Generate, translate, extract documents, inspect credits | `EGOVAI_ACCESS_CODE`                                           | Consumes credits                |
| eGov Compass  | Query national budget records and dashboards            | `EGOVCOMPASS_API_KEY`                                          | Read-only                       |
| eMessage      | Send SMS messages                                       | `EMESSAGE_ACCESS_TOKEN`                                        | Sends messages                  |
| eGovChain     | Call an EVM-compatible JSON-RPC service                 | None                                                           | Raw transactions write to chain |
| eReport       | Submit and view citizen reports                         | `EREPORT_ACCESS_TOKEN`                                         | Submits reports and OTPs        |
| eGov SSO      | Exchange login codes and retrieve citizen profiles      | `EGOVSSO_PARTNER_CODE`, `EGOVSSO_PARTNER_SECRET`               | Creates tokens                  |
| eVerify       | Verify identities and QR payloads                       | `EVERIFY_CLIENT_ID`, `EVERIFY_CLIENT_SECRET`, `EVERIFY_PUBKEY` | Processes identity data         |
| eGovPay       | Create, inspect, and void payments                      | `EGOVPAY_API_KEY`, `EGOVPAY_SETTLEMENT_TEMPLATE_UUID`          | Changes payment state           |
| Face Liveness | Create sessions and retrieve verification results       | `EGOVLIVENESS_API_KEY`                                         | Starts biometric sessions       |

<Warning>
  All listed hosts except the default eGovChain RPC are **partner staging or hackathon systems**.
  Access is governed by provider agreements and credentials.
</Warning>
