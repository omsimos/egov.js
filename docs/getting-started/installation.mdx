# Install egov.js

## Requirements

**Node.js 22.18 or newer** is supported for server applications. Other modern
runtimes can use explicitly configured clients when they provide Fetch, Web
Crypto, `Blob`, and `FormData`.

## npm installation

<Warning>
  `egov.js` is **not yet listed on npm**. These commands become available with the first public
  package release.
</Warning>

**After publication, add `egov.js`** with the package manager used by your
application.

<CodeGroup>
```bash pnpm
pnpm add egov.js
```

```bash npm
npm install egov.js
```

```bash yarn
yarn add egov.js
```

</CodeGroup>

<Note>
  The package ships **ESM, CommonJS, and TypeScript declarations**. Use a service subpath when an
  application only needs one integration.
</Note>

## Verify the import after installation

**Import one service client** to confirm that package resolution and TypeScript
declarations are working.

```ts
import { eGovChainApi } from "egov.js/eGovChain";

console.log(eGovChainApi.catalog.name);
```

Continue with the [quickstart](./quickstart.mdx) after installation.
