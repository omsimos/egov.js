# Install egov.js

## Requirements

**Node.js 22.18 or newer** is supported for server applications. Other modern
runtimes can use explicitly configured clients when they provide Fetch, Web
Crypto, `Blob`, and `FormData`.

## Install the private release

**npm publishing is paused** while the source repository remains private. Clone
the repository with an authorized GitHub account and create the exact tarball
that would be sent to npm.

```bash
git clone https://github.com/omsimos/egov.js.git
cd egov.js
pnpm install
pnpm pack
```

**Install the generated archive** in another project with the package manager of
your choice.

<CodeGroup>
```bash pnpm
pnpm add /path/to/egov.js-0.1.0.tgz
```

```bash npm
npm install /path/to/egov.js-0.1.0.tgz
```

```bash yarn
yarn add file:/path/to/egov.js-0.1.0.tgz
```

</CodeGroup>

<Note>
  The tarball contains only **compiled output and package metadata**. Source, tests, documentation
  build dependencies, and local environment files are not published.
</Note>

## Future npm installation

**Public registry installation** will use the unscoped package after publishing is
enabled.

```bash
pnpm add egov.js
```

Continue with the [quickstart](./quickstart.mdx) after installation.
