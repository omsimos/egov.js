# Install egov.js

## Requirements

Node.js 22.18 or newer is supported. Other modern runtimes need Fetch, `Blob`,
and `FormData`.

## npm installation

<CodeGroup>
```bash pnpm
pnpm add egov.js
```

```bash npm
npm install egov.js
```

```bash yarn
yarn add egov.js
```

</CodeGroup>

## Verify the import

The root entry exports the generated client, tagged static service classes, and
TypeScript types:

```ts
import { createClient, egovChain } from "egov.js";

const client = createClient({
  baseUrl: "https://hackathon-blockchain.e.gov.ph",
});

console.log(typeof egovChain.jsonRpc, client);
```

Continue with the [quickstart](./quickstart.mdx) after installation.
